# Changelog

## v1.0.0 — 23 November 2026

- Built the complete 180-chapter, 14-part **Indian House-Building & Civil Engineering Pocketbook** as a 100% local, offline, white-paper React + Vite + Tailwind web application.
- Authored structured data registers for 27 core BIS/NBC/Government standards, 9 active 2025–2026 edition-check flags, 53 official Indian authority portal links, 11 regional engineering profiles, 13 State/UT statutory rule entries, 13-point Site Information Pack, 44 glossary terms, and 7 stage hold-point field inspection checklists.
- Created 16 interactive, zoomable white-paper SVG engineering diagrams with numbered callouts.
- Implemented offline `jsPDF` exporter (Complete 180-Chapter Pocketbook, Single Part, or Single Chapter) and Illustrated A4 Print-Book mode (`Print → Save as PDF`).
- Added instant offline full-text search, auto/custom screen text scaling (`Compact / Auto / Comfortable / Large`), distraction-free reading mode, low-bandwidth diagram collapse toggle, safe non-structural SI/quantity estimators, interactive practice labs, and `localStorage` persistence with progress reset.
